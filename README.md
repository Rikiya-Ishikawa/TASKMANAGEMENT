## 設計ドキュメント

### 要件定義書 v1.1

#### プロジェクト概要
個人用のTrello風タスク管理Webアプリを作成する。

#### 利用者・利用場面
| 項目 | 内容 |
|------|------|
| 利用者 | 自分1人（シングルユーザー） |
| 利用場面 | 仕事・プライベート両方（公私混在） |

#### 機能要件

**ボード**
- ボードは1枚固定

**リスト（列）**
- 「未着手」「進行中」「完了」の3列固定
- 追加・削除・名前変更は不要

**カード**
- カードを追加できる（タイトルのみ）
- カードを削除できる
- カードをドラッグ＆ドロップで別リストへ移動できる

#### 非機能要件（作らないもの）
- ログイン・認証機能
- 締め切り日・ラベル・説明文・添付ファイル
- 複数ボード管理
- リストの追加・削除・名前変更
- スマートフォン対応（レスポンシブ）

#### 画面遷移設計

**状態①：通常状態**
- ボードにカードが一覧表示される

**状態②：カード追加中（＋カード追加クリック後）**
- 入力欄と「追加」「✕」ボタンが出現
- 追加ボタン or Enterキー → タイトルが空でなければカード追加 → 状態①へ
- ✕ボタン or Escキー → 入力欄を閉じる → 状態①へ

**状態③：カード削除（🗑クリック）**
- 確認なしで即削除 → 状態①のまま

**状態④：ドラッグ中**
- ドラッグ中は移動先リストをハイライト表示
- ドロップで別リストへ移動 → 状態①へ

#### 概念データ設計

```
┌──────────────┐         ┌──────────────┐
│   リスト      │ 1     多 │   カード      │
│──────────────│─────────│──────────────│
│ 名前          │         │ タイトル      │
│ 表示順        │         │ 所属リスト    │
└──────────────┘         │ 表示順        │
                         └──────────────┘
```

| エンティティ | 持つ情報 | 備考 |
|------------|---------|------|
| リスト | 名前、表示順 | 3件固定（未着手／進行中／完了） |
| カード | タイトル、所属リスト、表示順 | 追加・削除・移動の対象 |
