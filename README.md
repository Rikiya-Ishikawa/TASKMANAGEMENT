## 設計ドキュメント

### 要件定義書 v1.1

#### プロジェクト概要
個人用のTrello風タスク管理Webアプリを作成する。

#### 利用者・利用場面
| 項目 | 内容 |
|------|------|
| 利用者 | 自分1人（シングルユーザー） |
| 利用場面 | 仕事・プライベート両方（公私混在） |

#### 機能要件

**ボード**
- ボードは1枚固定

**リスト（列）**
- 「未着手」「進行中」「完了」の3列固定
- 追加・削除・名前変更は不要

**カード**
- カードを追加できる（タイトルのみ）
- カードを削除できる
- カードをドラッグ＆ドロップで別リストへ移動できる

#### 非機能要件（作らないもの）
- ログイン・認証機能
- 締め切り日・ラベル・説明文・添付ファイル
- 複数ボード管理
- リストの追加・削除・名前変更
- スマートフォン対応（レスポンシブ）

#### 画面遷移設計

**画面遷移図**

```
                    ┌─────────────────────────┐
                    │                         │
          ┌─────────▼──────────┐              │
          │    状態①            │              │
          │    通常状態          │◀─────────────┤
          │                    │              │
          └──┬──────┬──────┬───┘              │
             │      │      │                  │
     ＋カード │   🗑  │  カード│                  │
      追加    │ クリック│ ドラッグ│                  │
      クリック │      │      │                  │
             ▼      │      ▼                  │
    ┌──────────────┐ │ ┌──────────────┐        │
    │   状態②       │ │ │   状態④       │        │
    │ カード追加中   │ │ │  ドラッグ中   │        │
    └──────┬───────┘ │ └──────┬───────┘        │
           │         │        │                │
     ┌─────┴──────┐  │    ドロップ              │
     │            │  │        │                │
  [追加] or   [✕] or │        └────────────────┘
  Enterキー  Escキー │             カード移動完了
     │            │  │
     │（空でない）  │  │ 即削除
     │            │  └──────────────────────────┘
     └────────────┘
          ↓
        状態①へ
```

**各状態の説明**

| 状態 | 画面の様子 |
|------|----------|
| 状態①通常状態 | カード一覧が表示されている |
| 状態②カード追加中 | ＋クリックで入力欄と追加／✕ボタンが出現 |
| 状態④ドラッグ中 | カードをつかんでいる。移動先リストがハイライト |

**遷移の条件**

| 操作 | 遷移 |
|------|------|
| ＋カード追加クリック | 状態① → 状態② |
| 追加ボタン or Enterキー（タイトルあり） | 状態② → 状態①（カード追加） |
| ✕ボタン or Escキー | 状態② → 状態① |
| 🗑クリック | 状態①のまま（即削除） |
| カードをドラッグ開始 | 状態① → 状態④ |
| ドロップ | 状態④ → 状態①（カード移動） |

#### 概念データ設計

```
┌──────────────┐         ┌──────────────┐
│   リスト      │ 1     多 │   カード      │
│──────────────│─────────│──────────────│
│ 名前          │         │ タイトル      │
│ 表示順        │         │ 所属リスト    │
└──────────────┘         │ 表示順        │
                         └──────────────┘
```

| エンティティ | 持つ情報 | 備考 |
|------------|---------|------|
| リスト | 名前、表示順 | 3件固定（未着手／進行中／完了） |
| カード | タイトル、所属リスト、表示順 | 追加・削除・移動の対象 |

### 詳細設計

#### 物理データ設計（テーブル定義）

**listsテーブル**

| カラム名 | データ型 | 制約 | 説明 |
|---------|---------|------|------|
| id | INTEGER | PRIMARY KEY | 識別番号（自動採番） |
| name | TEXT | NOT NULL | リスト名（未着手など） |
| position | INTEGER | NOT NULL | 表示順（左から1,2,3） |

**cardsテーブル**

| カラム名 | データ型 | 制約 | 説明 |
|---------|---------|------|------|
| id | INTEGER | PRIMARY KEY | 識別番号（自動採番） |
| title | TEXT | NOT NULL | カードのタイトル |
| list_id | INTEGER | NOT NULL, FOREIGN KEY | 所属するリストのid |
| position | INTEGER | NOT NULL | リスト内での表示順 |
| created_at | TEXT | NOT NULL | 作成日時 |

**テーブルの関係**

```
lists                    cards
┌──────────────┐         ┌──────────────────┐
│ id           │◀────────│ list_id          │
│ name         │  1対多   │ id               │
│ position     │         │ title            │
└──────────────┘         │ position         │
                         │ created_at       │
                         └──────────────────┘
```

#### API設計

| メソッド | URL | 説明 |
|---------|-----|------|
| GET | /lists | 全リストとカードを取得する |
| POST | /cards | カードを新規作成する |
| DELETE | /cards/{id} | 指定したカードを削除する |
| PATCH | /cards/{id} | カードを更新する（移動時に使用） |

**GET /lists**
```json
// レスポンス
[
  {
    "id": 1,
    "name": "未着手",
    "cards": [
      { "id": 1, "title": "企画書作成", "position": 1 },
      { "id": 3, "title": "会議の準備", "position": 2 }
    ]
  },
  {
    "id": 2,
    "name": "進行中",
    "cards": [
      { "id": 2, "title": "メール返信", "position": 1 }
    ]
  },
  {
    "id": 3,
    "name": "完了",
    "cards": []
  }
]
```

**POST /cards**
```json
// リクエスト
{ "title": "新しいタスク", "list_id": 1 }

// レスポンス
{ "id": 4, "title": "新しいタスク", "list_id": 1, "position": 3 }
```

**DELETE /cards/{id}**
```json
// リクエスト：なし（URLのidで指定）例：DELETE /cards/4

// レスポンス
{ "message": "deleted" }
```

**PATCH /cards/{id}**
```json
// リクエスト
{ "list_id": 2, "position": 1 }

// レスポンス
{ "id": 1, "title": "企画書作成", "list_id": 2, "position": 1 }
```
