# 要件定義書 v1.1

## プロジェクト概要

個人用のTrello風タスク管理Webアプリを作成する。

---

## 利用者・利用場面

| 項目 | 内容 |
|------|------|
| 利用者 | 自分1人（シングルユーザー） |
| 利用場面 | 仕事・プライベート両方（公私混在） |

---

## ユースケース

### ユースケース図

```
┌─────────────────────────────────────────┐
│              タスク管理アプリ              │
│                                         │
│         ┌─────────────────┐             │
│         │ タスク一覧を     │             │
│         │ 確認する         │             │
│         └─────────────────┘             │
│                                         │
│         ┌─────────────────┐             │
│  ユーザ ─┤ カードを追加する  │             │
│  （自分）│                 │             │
│         └─────────────────┘             │
│                                         │
│         ┌─────────────────┐             │
│         │ カードを削除する  │             │
│         └─────────────────┘             │
│                                         │
│         ┌─────────────────┐             │
│         │ カードを別リスト  │             │
│         │ へ移動する       │             │
│         └─────────────────┘             │
└─────────────────────────────────────────┘
```

### ユースケース一覧

| No | アクター | ユースケース | 説明 |
|----|---------|------------|------|
| UC-01 | ユーザ | タスク一覧を確認する | ボードを開き、全カードを確認する |
| UC-02 | ユーザ | カードを追加する | ＋ボタンからタイトルを入力して追加する |
| UC-03 | ユーザ | カードを削除する | 🗑ボタンでカードを削除する |
| UC-04 | ユーザ | カードを別リストへ移動する | ドラッグ＆ドロップで列を移動する |

---

## 機能要件

**ボード**
- ボードは1枚固定

**リスト（列）**
- 「未着手」「進行中」「完了」の3列固定
- 追加・削除・名前変更は不要

**カード**
- カードを追加できる（タイトルのみ）
- カードを削除できる
- カードをドラッグ＆ドロップで別リストへ移動できる

---

## 非機能要件（作らないもの）

- ログイン・認証機能
- 締め切り日・ラベル・説明文・添付ファイル
- 複数ボード管理
- リストの追加・削除・名前変更
- スマートフォン対応（レスポンシブ）
