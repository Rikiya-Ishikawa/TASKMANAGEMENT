## 画面遷移設計

### 画面遷移図

```
                    ┌─────────────────────────┐
                    │                         │
          ┌─────────▼──────────┐              │
          │    状態①            │              │
          │    通常状態          │◀─────────────┤
          │                    │              │
          └──┬──────┬──────┬───┘              │
             │      │      │                  │
     ＋カード │   🗑  │  カード│                  │
      追加    │ クリック│ ドラッグ│                  │
      クリック │      │      │                  │
             ▼      │      ▼                  │
    ┌──────────────┐ │ ┌──────────────┐        │
    │   状態②       │ │ │   状態④       │        │
    │ カード追加中   │ │ │  ドラッグ中   │        │
    └──────┬───────┘ │ └──────┬───────┘        │
           │         │        │                │
     ┌─────┴──────┐  │    ドロップ              │
     │            │  │        │                │
  [追加] or   [✕] or │        └────────────────┘
  Enterキー  Escキー │             カード移動完了
     │            │  │
     │（空でない）  │  │ 即削除
     │            │  └──────────────────────────┘
     └────────────┘
          ↓
        状態①へ
```

### 各状態の説明

| 状態 | 画面の様子 |
|------|----------|
| 状態①通常状態 | カード一覧が表示されている |
| 状態②カード追加中 | ＋クリックで入力欄と追加／✕ボタンが出現 |
| 状態④ドラッグ中 | カードをつかんでいる。移動先リストがハイライト |

### 遷移の条件

| 操作 | 遷移 |
|------|------|
| ＋カード追加クリック | 状態① → 状態② |
| 追加ボタン or Enterキー（タイトルあり） | 状態② → 状態①（カード追加） |
| ✕ボタン or Escキー | 状態② → 状態① |
| 🗑クリック | 状態①のまま（即削除） |
| カードをドラッグ開始 | 状態① → 状態④ |
| ドロップ | 状態④ → 状態①（カード移動） |

## 概念データ設計

```
┌──────────────┐         ┌──────────────┐
│   リスト      │ 1     多 │   カード      │
│──────────────│─────────│──────────────│
│ 名前          │         │ タイトル      │
│ 表示順        │         │ 所属リスト    │
└──────────────┘         │ 表示順        │
                         └──────────────┘
```

| エンティティ | 持つ情報 | 備考 |
|------------|---------|------|
| リスト | 名前、表示順 | 3件固定（未着手／進行中／完了） |
| カード | タイトル、所属リスト、表示順 | 追加・削除・移動の対象 |
